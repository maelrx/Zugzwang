# Update literature map

## Workflow

1. Locate the primary paper/proceedings/repository.
2. Verify latest version, date and artifact availability.
3. Capture question, model, data, training, inference protocol, H/K assistance, metrics, results and limitations.
4. Distinguish authors' result from your inference.
5. Compare only within compatible protocols.
6. Note contamination, rating, retry and engine-leakage risks.
7. Add bibliography and literature-map entry.
8. Update architecture/experiment agenda only when the source changes a design assumption.
9. Label post-cutoff update with exact date.
10. Preserve older source notes when a preprint changes materially.

## Source hierarchy

paper/proceedings → official repository/model card/dataset card → official documentation → author communication. Avoid secondary summaries for load-bearing claims.
