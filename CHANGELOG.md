# Changelog

All notable changes to the foundation corpus are documented here.

## [0.1.0-foundation] - 2026-08-12

### Added

- greenfield product and research constitution;
- complete architecture and system-design corpus;
- 45 ADR decision records, including human-owned gates;
- v0.1 experiment catalog for representation, grounding, skills, multimodality, and demonstrations;
- strict draft schemas for manifests, events, metrics, knowledge packets, bundles, and provider capabilities;
- Codex `AGENTS.md` hierarchy and reusable engineering skills;
- M0 through M6 roadmap and bootstrap issue backlog;
- documentation validation scripts and contribution templates;
- archived source dossier and initial technical design.

### Deliberately not added

- executable runtime;
- dependency lockfile;
- selected software license;
- chess rules dependency;
- production provider credentials or model defaults;
- Web UI or API server.
