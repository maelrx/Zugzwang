# Foundation delivery report

## Delivered

- research foundation and literature map;
- initial causal experiment program;
- product vision, scope, personas and OSS/hosted perspective;
- modular-monolith architecture and detailed system design;
- functional/non-functional requirements and traceability;
- 45 ADRs, including proposed human-owned decisions;
- 12 machine-readable Mestre Mael decision gates;
- protocol specifications and draft JSON Schemas;
- seven-milestone roadmap and 72-item bootstrap backlog;
- 20 Codex Agent Skills plus root/nested AGENTS.md;
- engineering, testing, security, migration, release and governance guides;
- package/plugin boundary placeholders and scaffold templates;
- GitHub contribution templates and foundation CI;
- source archive, provenance manifest and validation scripts.

## Deliberately not delivered

- runtime code;
- active pyproject/uv.lock;
- LICENSE;
- provider credentials or outputs;
- Stockfish binary;
- Web/API/UI;
- claims from executed Zugzwang experiments.

These omissions are controls, not missing polish. They prevent pre-scaffold documentation from pretending that unresolved human choices or unexecuted software already exist.
