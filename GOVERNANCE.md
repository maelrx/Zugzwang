# Governance

## Current phase

Zugzwang is founder-led during the pre-1.0 foundation and protocol-discovery phase. Mestre Mael is the final decision authority for product, license, budget, public claims and compatibility commitments.

## Maintainers

Maintainers may merge implementation and documentation changes inside accepted ADRs and requirements. High-risk surfaces require designated review:

- core/protocol schemas;
- database migrations/upcasters;
- security/retention;
- release/supply chain;
- scientific claim wording.

## Decision process

- reversible implementation choice: PR rationale;
- architectural choice: ADR;
- human-owned/irreversible choice: Decision Gate + ADR;
- scientific protocol: Experiment Card/preregistration;
- emergency security fix: security process, followed by retrospective ADR if architecture changed.

## Future evolution

Contributor roles, voting and steering governance are deferred until there are sustained external maintainers. Governance will not be simulated before a real community exists.
