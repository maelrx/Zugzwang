# ADR-038: Idioma canônico da documentação


## Contexto

O operador e a primeira equipe trabalham em PT-BR. A adoção científica internacional favorece inglês.

## Recomendação

README público bilíngue; documentação canônica PT-BR durante M0-M2; migração para English canonical antes do primeiro release internacional, se houver capacidade de manter consistência.

## Opções

1. tudo inglês;
2. tudo PT-BR;
3. canonical English + operator guide PT-BR;
4. canonical PT-BR + public English entry.

## Trade-offs

Bilinguismo integral duplica drift. Um idioma canônico é necessário. A escolha afeta contribuição e velocidade.

## Reversibilidade

Alta tecnicamente, alta carga editorial.
