# Playbook de execução científica

## Before execution

- ratify relevant gates;
- freeze experiment card, manifests, dataset and source commit;
- validate pairing/randomization and power assumptions;
- run fake and cheapest-model pilots;
- approve budget and artifact policy;
- verify provider snapshots and evaluator versions;
- create immutable run plan hash.

## During execution

- do not modify condition prompts or selection rules;
- monitor infrastructure health, not outcomes for cherry-picking;
- classify provider incidents separately;
- pause when corruption, drift or budget breach is suspected;
- preserve failed attempts and protocol deviations.

## After execution

- finalize bundles before analysis;
- analyze against preregistered outcomes first;
- label exploratory analyses;
- report exclusions and missingness;
- calculate uncertainty at paired unit;
- run claims/evidence audit;
- derive public artifacts under approved policy;
- archive exact analysis environment and queries.
