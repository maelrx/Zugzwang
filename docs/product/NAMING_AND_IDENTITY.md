# Naming and project identity

## Current naming layers

| Layer | Working name | Status |
|---|---|---|
| Project/repository | Zugzwang | established working identity |
| Product category | Zugzwang Research Kernel | accepted positioning |
| Implementation corpus | Zugzwang Engine | descriptive, not a separate product |
| Python distribution | pending GATE-012 | unresolved |
| CLI command | pending GATE-004 | recommendation: `zugzwang` + `zgw` |
| Hosted product | unnamed | outside v0.1 |

## Naming principle

“Research Kernel” communicates the durable category: execution, protocol, evidence and attribution. “Engine” may describe the implementation but must not imply a chess engine competing with Stockfish. The project does not claim to be an Elo leaderboard or a model.

## External wording

Preferred:

> Zugzwang is an attribution-first research kernel for reproducible LLM decision experiments, starting with chess.

Avoid:

- “the strongest chess LLM” without a specific experiment;
- “universal agent operating system”;
- “AI chess engine” when the system is a harness;
- “open source” before a license is committed.
