# M6: Primeira suite científica

## Objetivo

Usar o kernel para produzir um primeiro conjunto de resultados causais sobre representação, grounding, multimodalidade, skills e demonstrations.

## Entry gates

- GATE-005 e GATE-011 ratificados;
- experiment cards congelados;
- budget projection aprovado;
- datasets e splits auditados;
- M5 release candidate.

## Sequência

1. Pilotos fake e modelos baratos.
2. Power/sensitivity simulation.
3. Congelar preregistration e manifests.
4. Executar REP-001 e GROUND-001.
5. Executar SKILL-001 com controles causais.
6. Executar MM-001/MM-002 em modelos com imagem nativa.
7. Executar DEMO-001 com token budget pareado.
8. Corrigir apenas falhas de infraestrutura, nunca outcomes.
9. Promover condições predefinidas para FULL-001.
10. Publicar bundles permitidos, analysis code e claims ledger.

## Exit gate

Cada claim possui evidence tier, confidence interval, costs, protocol coordinate, raw/private evidence policy and reproducible bundle. Resultados nulos ou negativos permanecem publicáveis.
