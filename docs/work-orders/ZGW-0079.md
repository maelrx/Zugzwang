## Implementation slices

1. Evidence contract and direct references.
2. Provider wire/telemetry retention and sanitization.
3. RulesKernel and capability-scoped LegalityGateway.
4. Explicit repair profiles and opaque action handles.
5. Immutable SearchWorkspace, endogenous memory and pure search tools.
6. R6-BatchedTree regression and documentation.

## Exit evidence

- Fresh and forward migrations pass, with old bundle fixture import intact.
- One trace proves binary legality cannot expose a legal-action set.
- One trace proves enumeration is H3 and is recorded as a protocol violation
  when a lower condition declares otherwise.

  linked from their attempt/step rows.
- Evaluation generations are independently queryable.
- Search branches are immutable, transposition-aware and cannot resolve
  `evaluation://` artifacts.
- Offline tests, ruff and pyright pass; limitations are documented honestly.
