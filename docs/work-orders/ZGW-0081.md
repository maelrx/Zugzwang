## Implementation slices

1. Add public behavior tests for legal enumeration, branch validation,
   retrieval provenance and memory-mode isolation.
2. Add the model strategy with mapper, variant analyst and final reviewer roles.
3. Wire R7 search/memory into the durable coordinator and persist/reseed only
   the explicit episode-scoped mode.
4. Add paired fake manifests for offline comparison and update protocol docs.

## Experimental contract

- R7 is an explicit retrieved-memory/legality-tree condition, not a silent
  change to R5.
- All three model roles see the current legal root-action set and the bounded
  memory projection.
- Legal moves are enumerable; illegal moves are only observable as proposed
  probes rejected by the RulesKernel. The full complement of illegal strings is
  not enumerated.
- SearchWorkspace branches are per decision and immutable. Persistent memory
  carries selected model notes across turns within one episode, while
  episodic memory starts empty on every turn.
- The two memory conditions share model, prompts, branch limits and budgets.
  Only memory mode changes.

## Exit evidence

- Unit and integration tests prove the gateway lease and SearchWorkspace
  branch behavior.
- A trace records legal count/hash, illegal probes, branches, retrieval IDs,
  memory mode and seed count.
- Persistent mode can be reconstructed from the latest committed search graph
  after a coordinator restart; episodic mode cannot see prior-turn notes.
- A real provider/Stockfish full-game run is recorded after explicit operator authorization.
