## Controlled conditions

All five conditions use the same model, provider route, starting position,
Stockfish policy, medium reasoning effort, 32k output ceiling, no ply cap, no
call cap and one episode. Only the following search hypothesis changes:

1. episodic memory, four root candidates, all legal child reply sets;
2. persistent memory, four root candidates, all legal child reply sets;
3. persistent memory plus forced-reply/king-safety checklist;
4. persistent memory, six root candidates, all legal child reply sets;
5. persistent memory, four root candidates, candidate-only child reply sets.

The first condition is the memory control. The other conditions are
exploratory ablations and are not a preregistered strength ranking.

## Exit evidence

- one DecisionTrace with one provider CallRecord per model turn;
- legal root set and child reply sets recorded with hashes;
- rejected illegal probes and all SearchWorkspace edges persisted;
- persistent and episodic memory scopes visible in the trace;
- five real games and post-hoc Stockfish evaluation recorded separately by
  condition;
- no private chain-of-thought claim; only provider telemetry and structured
  output are analyzed.
