localEngine. O CB-WO-10 adiciona UMA superfície causal pós-hoc: um script
`build_cognitive_viewer.py` (irmão do `build_readonly_viewer.py`) que exporta
decisão → snapshot JSON redatado (rounds, operações com envelopes, observações,
budget, memórias), um lib `cognitive.ts` (tipos + loader de bundle.json), e o
componente `CognitiveTimeline.tsx` (timeline navegável por teclado). O snapshot
é dado morto: nenhum fetch, nenhum engine, nenhum write-back.
