## Motivation

The operator opened a parallel Codex track to the muse-only directive (same way
the Gemini track was opened). The Codex CLI (`codex-cli 0.153.4`) is installed,
authenticated via `~/.codex/auth.json` (no API key in manifests), and exposes a
headless mode (`codex exec --json`) suitable for one-call-per-inference adapters.

## Requirements

- R1: New plugin `plugins/provider-codex-cli` exposing backend id
  `provider.codex_cli` through entry-point group `zugzwang.providers`, mirroring
  the proven `provider-antigravity-cli` structure (one inference call = one
  headless CLI invocation; no agent loop, no hidden context).
- R2: The adapter flattens the canonical request into a single prompt with the
  SAME tool protocol as antigravity (`[AVAILABLE TOOLS]` + JSON command blocks,
  `board_finalize` shorthand) so `chess.cognitive_navigation` works unchanged.
- R3: Output parsed from `codex exec --json` JSONL events: last
  `item.completed` agent_message = response text; `turn.completed` usage =
  provider-sourced token usage (GATE-009: cost stays unknown).
- R4: Config keys (task `backend_config`): `model` (default `gpt-5.6-luna` — ID interno da LUNA; o default do config do operador, gpt-6-astra, é OUTRO frontier e NÃO é o alvo),
  `executable`, `timeout_seconds` (default 300), `reasoning_effort`
  (maps to `-c model_reasoning_effort=...`), `max_output_tokens` (optional,
  maps to `-c model_max_output_tokens=...`), `single_flight_lock` (optional,
  default OFF — parallel runs are an explicit operator decision).
- R5: Timeout maps to `ProviderTimeoutError` (ZGZ-PROVIDER_TRANSPORT-002,
  timeout_unknown fail-closed: no blind retry). Non-zero exit or missing
  agent_message maps to `ProviderResponseError`; missing binary maps to
  `ProviderConnectionError`.
- R6: Offline tests only (no network, no real CLI): fake executable scripts.
- R7: Runtime wiring: `provider.codex_cli` branch in
  `zugzwang_runtime.application.durable_services._backend_for`.
- R8: Validation with a real LUNA (`gpt-5.6-luna`) smoke (operator-authorized spend:
  single 2-ply game in an isolated workspace) before any campaign run.
- R9: 5 full-game manifests (best-evidenced setups, effort high) launched
  concomitantly in 5 ISOLATED workspaces (operator-ordered concurrency; codex
  does not share the opencode router, so the cb2 429-cascade single-flight
  rule does not apply).
