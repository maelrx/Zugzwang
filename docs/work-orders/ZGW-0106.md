## Gateway facts (verified, not assumed)

Source: platform machine-readable reference (`/llms.txt`, 854 lines, fetched
2026-09-08) + live probes against `deepseek-v4-flash`.

- Base URL: `https://api.experientiallabs.ai/v1`; auth `Authorization: Bearer
  xpl_…`; model slugs from `GET /v1/models` (330 models listed for this key).
- `POST /v1/chat/completions` is standard OpenAI shape. Native `tools` +
  `tool_choice: auto` validated live: the model returned a real
  `board_expand` call with `finish_reason: tool_calls`.
- `reasoning_effort` is served, never rejected (snaps to nearest tier;
  substitutions disclosed in `x-experiential-ignored-parameters`).
- `seed` is advertised in the catalog (`supported_params.seed: true`) but the
  gateway answers 400 `unsupported_parameter` on this route (probed live).
  The adapter strips it and records the drop in result warnings.
- DeepSeek lanes expose plaintext `reasoning_content` on the assistant
  message (probed: present on tool-call replies); preserved as reasoning
  summary. Catalog `supports_parallel_tool_calls: false`.
- `usage.cost` stamped inline on every reply (BYOK settles 0 + `is_byok`).
  GATE-009: billed cost stays `unknown`; cost is wire evidence only.
- Errors: `insufficient_quota`/`insufficient_credits` and siblings (429) mean
  retrying is pointless → `ProviderResponseError`. Throttled routes
  (`unavailable_route`, `gateway_overloaded`, 502/503/504) →
  `ProviderThrottlingError` (runtime backoff + Retry-After). 401 (bad key) →
  `ProviderConnectionError`; 403 (slug not granted) → `ProviderResponseError`.

## Requirements

- R1: New plugin `plugins/provider-experiential-labs` exposing backend id
  `provider.experiential_labs` (OpenAI chat-completions wire over httpx; no
  agent loop, no hidden context).
- R2: Canonical request lowering: system/user/assistant/tool messages, native
  `tools` (OpenAI function shape), `max_tokens`, `temperature`, `stop`,
  `reasoning_effort`, `response_format: json_object` for json constraints.
  Image parts refused pre-wire (`CapabilityMissingError`); `seed` stripped
  with a warning (gateway rejects it).
- R3: `usage.prompt_tokens`/`completion_tokens` → `TokenUsage` source
  PROVIDER; `reasoning_content` → reasoning summary telemetry; ignored-params
  disclosure → warnings. COST stays unknown (GATE-009).
- R4: Config keys (`backend_config`): `base_url` (default gateway),
  `api_key` (`env:` reference, resolved by runtime), `timeout_seconds`
  (default 120), `reasoning_effort`, `default_max_output_tokens`.
- R5: Error mapping per gateway facts above. Timeout → `ProviderTimeoutError`
  (fail-closed, no blind retry).
- R6: Offline contract tests only (httpx MockTransport, no network/secrets).
- R7: Runtime wiring: `provider.experiential_labs` branch in
  `zugzwang_runtime.application.durable_services._backend_for`.
- R8: Real smoke (operator-authorized spend): direct adapter call + 2-ply run
  before any campaign.
- R9: 3 full-game manifests (white vs SF-1320, `max_plies: null`, guard-medium
