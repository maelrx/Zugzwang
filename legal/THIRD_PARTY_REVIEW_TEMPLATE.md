# Third-party dependency/license review

```yaml
component:
  name: ""
  version: ""
  source: ""
  license: ""
  usage: runtime | optional-plugin | build | test | external-executable
  distributed: false
  linked_or_imported: false
  source_offer_required: unknown
  notices_required: []
  compatibility_with_project_license: pending
  reviewer: null
  reviewed_at: null
```

## Questions

- Is the dependency imported/linked or only invoked as an external process?
- Are binaries redistributed?
- Are model/data licenses separate from code?
- Does the license constrain hosted use, outputs or commercial embedding?
- Are attribution, source, notice or patent obligations satisfied?

This template is an engineering aid, not legal advice.
