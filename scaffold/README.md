# Scaffold templates

These are proposals, not active build files. `bootstrap-workspace` substitutes the accepted human decisions and then moves generated files into canonical root/package locations. Do not copy blindly.

- `pyproject.root.toml.template`: root uv workspace/tooling proposal;
- `package.pyproject.toml.template`: package metadata skeleton;
- `bootstrap-manifest.yaml`: gate-to-file plan;
- `CI_WORKFLOW.yml.template`: post-M0 offline CI proposal.
