# Schemas

JSON Schemas use JSON Schema Draft 2020-12.

## Generated contracts (authoritative, regenerated from code)

Generated by `zugzwang schema` from the strict Pydantic models in
`zugzwang-core`. Never edit by hand; regeneration is a CI-gated command.

- `experiment-manifest.zgw.dev-v1alpha1.schema.json` — source manifest (author-facing)
- `experiment-manifest-resolved.zgw.dev-v1alpha1.schema.json` — resolved manifest (immutable, hashable)
- `event.zgw.dev-v1alpha1.schema.json` — scientific event envelope
- `metric-observation.zgw.dev-v1alpha1.schema.json`
- `metric-definition.zgw.dev-v1alpha1.schema.json`
- `model-request.zgw.dev-v1alpha1.schema.json` — canonical provider request

## Draft-to-generated comparison (M0 exit evidence)

The foundation drafts used `schema_version: "0.1.0"` with a flat shape
(`experiment`/`task`/`factors`/`strategy`/`provider`/`protocol`/`budget`/
`evaluation`/`artifacts`/`runtime`). The executable v0.1 protocol follows the
greenfield technical design instead (`api_version: zgw.dev/v1alpha1`,
`metadata`/`spec` with `matrix`, `players`, `protocol`, `budget`,
`evaluation`, `artifacts`), which Mestre Mael designated as the build base on
2026-08-16. Key differences:

| Draft 0.1.0 | Generated v1alpha1 | Notes |
|---|---|---|
| `factors.dimensions` | `spec.matrix.parameters` | `product`/`zip` semantics preserved |
| `provider` (single) | per-player `players.<color>.model` | two players with independent policy/model |
| `protocol.assistance.declared_h/k` | `protocol.declared_assistance`/`declared_knowledge` | H0–H7 / K0–K4 taxonomies |
| `runtime.seed` | `spec.seed` | seeds derive episode-level deterministically |
| absent | `ManifestPatch` + `--set` | recorded in ResolvedManifest |
| absent | `protocol_hash`, condition IDs | stable per-condition identity |

Compatibility fixtures for the historical drafts are preserved under
`fixtures/contracts/`; readers for old bundles arrive with the migration
milestone (M5) per ADR-030.
